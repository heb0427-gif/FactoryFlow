# FactoryFlow

## 1. 프로젝트 소개
가상의 제조 설비와 작업지시, 생산실적, 알람을 관리하는
C++ 콘솔 기반 미니 MES입니다.

## 2. 개발 목적
- C++ 객체지향 설계 연습
- 자료구조를 실제 프로그램에 적용
- 제조업 생산관리 흐름 이해

## 3. 주요 기능
- 설비 관리
- 작업지시 관리
- 생산 이벤트 큐
- 실적 및 불량률 계산
- 설비 이상 알람
- 파일 저장 및 복구

## 4. 프로그램 구조
클래스 관계와 처리 흐름

## 5. 실행 화면
콘솔 화면 캡처

## 6. 핵심 구현
생산 이벤트 처리 과정
설비 상태 전이 검증
큐 적용 이유

## 7. 테스트
주요 테스트 케이스와 결과

## 8. 문제 해결
개발 중 발생한 오류와 해결 과정

## 9. 향후 개선
TCP 통신
멀티스레드
PostgreSQL
REST API
