# FactoryFlow

## 1. 프로젝트 소개

가상의 제조 설비와 작업지시, 생산실적, 알람을 관리하는 C++ 콘솔 기반 미니 MES입니다.

## 2. 개발 목적

- C++ 객체지향 설계 연습
- 자료구조를 실제 프로그램에 적용
- 제조업 생산관리 흐름 이해

## 3. 주요 기능 계획

- 설비 관리
- 작업지시 관리
- 생산 이벤트 큐
- 생산 실적 및 불량률 계산
- 설비 이상 알람
- 파일 저장 및 복구

## 4. 현재 구현 범위

### 설비 관리

- 설비 등록

- 설비 상세 조회
- 설비 상태 변경
- 설비 ID 중복 방지
- 설비 상태 전이 검증
- 잘못된 사용자 입력 처리

## 5. 코드 구조

### Equipment

- 설비 ID, 이름, 상태를 관리합니다.
- 설비 상태 전이 규칙을 검증합니다.

### WorkOrder

- 작업지시 ID, 제품 정보, 목표 수량, 우선순위를 관리합니다.
- 작업지시 상태 전이 규칙을 검증합니다.

### FactorySystem

- 등록된 설비와 작업지시를 관리합니다.
- 설비와 작업지시 간의 업무 규칙을 처리합니다.
- 설비 배정, 작업 시작, 일시정지, 재개, 완료, 취소를 담당합니다.

### EquipmentMenu

- 설비 관리 콘솔 메뉴를 담당합니다.
- 사용자 입력을 받아 FactorySystem에 요청을 전달합니다.

### WorkOrderMenu

- 작업지시 관리 콘솔 메뉴를 담당합니다.
- 사용자 입력을 받아 FactorySystem에 요청을 전달합니다.

### FactoryFlowMenu

- 상위 메뉴를 제공합니다.
- 설비 관리 메뉴와 작업지시 관리 메뉴를 연결합니다.

### FactoryFlow.cpp

- 프로그램의 진입점입니다.

## 6. 상태 전이 규칙

### 설비 상태

- STOPPED → RUNNING
- RUNNING → PAUSED, STOPPED, ERROR
- PAUSED → RUNNING, STOPPED, ERROR
- ERROR → STOPPED

허용되지 않은 상태 전이는 모두 거부합니다.

### 작업지시 상태

```
WAITING → READY → RUNNING
                  ├─ PAUSED → RUNNING
                  ├─ COMPLETED
                  └─ CANCELLED
```

## 10. 문제 해결

### `cin >>` 이후 `getline()`이 빈 문자열을 읽는 문제

`cin >>` 사용 후 입력 버퍼에 남아 있는 줄바꿈 문자 때문에 `getline()`이 즉시 종료되는 문제가 발생했습니다.

`cin.ignore()`를 사용해 입력 버퍼에 남은 줄바꿈 문자를 제거하여 해결했습니다.

### 정수가 아닌 메뉴 입력 처리

문자 입력 시 `cin`이 실패 상태가 되어 이후 입력도 처리되지 않는 문제가 있었습니다.

`cin.clear()`와 `cin.ignore()`를 사용하여 오류 상태를 초기화하고 입력 버퍼를 비운 뒤 다시 입력받도록 구현했습니다.
