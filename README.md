# FactoryFlow

## 1. 프로젝트 소개

가상의 제조 설비와 작업지시, 생산실적, 알람을 관리하는 C++ 콘솔 기반 미니 MES입니다.

## 2. 개발 목적

- C++ 객체지향 설계 연습
- 자료구조를 실제 프로그램에 적용
- 제조업 생산관리 흐름 이해

## 3. 주요 기능 계획

- 설비 관리
- 작업지시 관리
- 생산 이벤트 큐
- 생산 실적 및 불량률 계산
- 설비 이상 알람
- 파일 저장 및 복구

## 4. 현재 구현 범위

### 설비 관리

- 설비 등록
- 설비 전체 조회
- 설비 상세 조회
- 설비 상태 변경
- 설비 ID 중복 방지
- 설비 상태 전이 검증
- 잘못된 사용자 입력 처리

## 5. 코드 구조

- `Equipment`
  - 개별 설비의 ID, 이름, 상태를 관리합니다.
  - 설비 상태 변경 규칙을 검증합니다.

- `FactorySystem`
  - 등록된 전체 설비 목록을 관리합니다.
  - 설비 등록, 검색, 상태 변경 기능을 제공합니다.

- `EquipmentMenu`
  - 콘솔 메뉴 출력과 사용자 입력을 담당합니다.
  - 입력받은 요청을 `FactorySystem`에 전달합니다.

- `FactoryFlow.cpp`
  - 프로그램의 진입점입니다.
  - `FactorySystem`과 `EquipmentMenu` 객체를 생성하고 실행합니다.

## 6. 설비 상태 전이

허용되는 상태 전이는 다음과 같습니다.

- `STOPPED` → `RUNNING`
- `RUNNING` → `PAUSED`, `STOPPED`, `ERROR`
- `PAUSED` → `RUNNING`, `STOPPED`, `ERROR`
- `ERROR` → `STOPPED`

동일한 상태로의 변경과 위 목록에 없는 상태 전이는 허용하지 않습니다.

## 7. 실행 방법

1. Visual Studio에서 `FactoryFlow.sln`을 엽니다.
2. 프로젝트를 빌드합니다.
3. 프로그램을 실행합니다.
4. 콘솔 메뉴에서 원하는 기능의 번호를 입력합니다.

## 9. 테스트

현재 다음 항목을 직접 테스트했습니다.

- 정상적인 설비 등록
- 중복된 설비 ID 등록 방지

- 문자를 입력했을 때 정수 재입력 처리

## 10. 문제 해결

### `cin >>` 이후 `getline()`이 빈 문자열을 읽는 문제

`cin >>` 사용 후 입력 버퍼에 남아 있는 줄바꿈 문자 때문에
`getline()`이 즉시 종료되는 문제가 발생했습니다.

`cin.ignore()`를 사용해 입력 버퍼에 남은 문자를 제거했습니다.

### 정수가 아닌 메뉴 입력 처리

문자 입력 시 `cin`이 실패 상태가 되어 이후 입력도 처리되지 않는 문제가 있었습니다.

`cin.clear()`로 오류 상태를 해제하고,
`cin.ignore()`로 잘못된 입력을 제거한 뒤 다시 입력받도록 구현했습니다.
